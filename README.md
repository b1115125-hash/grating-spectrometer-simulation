# Grating Spectrometer Simulation

## 1. Project Overview

This project investigates the optical principles and performance limitations of a diffraction grating spectrometer.

The main objective is to understand how optical parameters influence spectral resolution, wavelength dispersion, and signal quality.

## 2. Theoretical Background

The project focuses on:

- Diffraction grating equation
- Angular dispersion and linear dispersion
- Entrance slit width and image broadening
- CCD pixel sampling and spectral resolution
- Signal-to-noise ratio (SNR)

## 3. Fundamental Equations

**Grating Equation**

\[
m\lambda = d(\sin\alpha+\sin\beta)
\]

Where:

- \(m\): Diffraction order
- \(\lambda\): Wavelength
- \(d\): Grating spacing
- \(\alpha\): Incident angle
- \(\beta\): Diffraction angle

**Angular Dispersion**

\[
\frac{d\beta}{d\lambda}=\frac{m}{d\cos\beta}
\]
